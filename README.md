# DM Assistant — Support

Public support site for the [DM Assistant mobile app](https://github.com/joshcookwv/dm-assistant-mobile): privacy policy and issue tracker, both linked from the app's Settings screen and from its Play Store listing.

Live at: https://joshcookwv.github.io/dm-assistant-mobile-support/

Report a bug or request a feature via [Issues](https://github.com/joshcookwv/dm-assistant-mobile-support/issues/new) — no need to see the app's source, this repo exists specifically so support/issues can be public even though the app's source repo is private.
